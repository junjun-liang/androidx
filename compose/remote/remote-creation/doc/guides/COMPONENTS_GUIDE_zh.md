# 构建 RemoteCompose 组件化示例指南

RemoteCompose 提供了两种不同的组件/修饰器系统。根据你偏好的 API 风格选择对应的指南：

### [过程式 API 指南](PROCEDURAL_COMPONENTS_GUIDE_zh.md) (`RemoteComposeContextAndroid`)
最适合在 `DemosCreation.java` 中注册的演示。使用原始单位（像素/浮点数）和过程式构建。

### [Compose 风格 API 指南](COMPOSE_COMPONENTS_GUIDE_zh.md) (`@RemoteComposable`)
最适合在 `DemosCompose.kt` 中注册的演示。使用标准 Compose 风格语法、单位（`dp`、`sp`）和状态管理。
