# AndroidX 项目业务流程文档

## 1. 概述

本文档详细描述 AndroidX 项目中的核心业务流程，包括开发流程、构建发布流程、API 管理流程、测试流程以及各核心模块的运行时业务流程。

---

## 2. 开发工作流

### 2.1 开发环境搭建流程

```
┌──────────────────────────────────────────────────────────────┐
│                   开发环境搭建流程                             │
```

### 3.3 API 管理流程

```
┌──────────────────────────────────────────────────────────────┐
│                    API 管理流程                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ① 开发者修改公共 API                                        │
│         │                                                    │
│         ▼                                                    │
│  ② checkApi 任务检测变更                                     │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  对比 api/current.txt 与当前源码生成的 API            │    │
│  │  → 无变更 → 通过                                     │    │
│  │  → 有变更 → 报告差异                                 │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ③ 开发者确认变更意图                                        │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  有意变更 → 运行 updateApi 更新 api/current.txt      │    │
│  │  无意变更 → 修复代码恢复 API                          │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ④ 版本兼容性验证                                            │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  checkApiRelease → 验证变更符合语义化版本保证         │    │
│  │  BCV → 验证 KMP 二进制兼容性                         │    │
│  │  → Minor/Bugfix 版本: 必须向后兼容                   │    │
│  │  → Major 版本: 允许破坏性变更                         │    │
│  └──────────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 各模块测试策略

| 模块 | 测试策略 | 特殊要求 |
|------|---------|---------|
| Compose | 截图测试 + JVM 逻辑测试 | 截图测试限 SDK 35 |
| Camera | Fakes/Test Doubles 优先 | Robolectric 用 `@Config(sdk=[TARGET_SDK])` |
| Room | 从 Java 迁移到 Kotlin 测试 | 使用 Kruth 断言库 |
| 通用 | Hamcrest → Kruth 迁移 | 100% 公共 API 测试覆盖 |

## 5. 核心运行时业务流程

### 5.1 Compose 渲染流程

```
┌──────────────────────────────────────────────────────────────┐
│                 Compose 渲染流程                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ① 状态变更触发                                              │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  State<T> 变更 → Runtime 标记为 dirty                │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ② 重组 (Recomposition)                                     │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  Composer 遍历组合树                                  │    │
│  │  → 识别 dirty 节点                                   │    │
│  │  → 调用 @Composable 函数重新执行                      │    │
│  │  → 智能跳过未变更的子树                               │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ③ 布局 (Layout)                                            │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  LayoutNode 树构建/更新                               │    │
│  │  → Measure 阶段: 父节点约束 → 子节点测量             │    │
│  │  → Layout 阶段: 子节点尺寸 → 父节点放置              │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ④ 绘制 (Draw)                                              │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  DrawNode 树遍历                                     │    │
│  │  → Canvas 绘制指令生成                               │    │
│  │  → Modifier.Node 链式绘制                            │    │
│  └──────────────────────────┬───────────────────────────┘    │
│                             ▼                                │
│  ⑤ 平台渲染                                                  │
│  ┌──────────────────────────────────────────────────────┐    │
│  │  Android: → RenderNode → Hardware Accelerated Canvas │    │
│  │  Desktop: → Swing/AWT Canvas                         │    │
│  │  iOS: → Core Graphics                                │    │
│  │  Web: → HTML Canvas / Wasm                           │    │
│  └──────────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────────┘
```
