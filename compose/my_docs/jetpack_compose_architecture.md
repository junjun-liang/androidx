## 1. 项目概述

### 1.1 项目简介

Jetpack Compose 是 Google 推出的现代 Android UI 工具包，采用声明式编程模型，使用 Kotlin 语言构建原生 Android 界面。它属于 AndroidX 生态系统的一部分，提供了一套完整的 UI 开发框架。

### 1.2 核心特性

- **声明式 UI**：使用 Composable 函数描述 UI，而非传统的 XML 布局
- **状态驱动**：UI 自动响应状态变化，无需手动更新视图
- **跨平台支持**：支持 Android、Desktop (JVM)、iOS、Web (JS/WASM) 等多平台
- **高度可组合**：通过组合小型组件构建复杂界面
- **Kotlin 优先**：完全基于 Kotlin 语言和协程构建

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 编程语言 | Kotlin |
| 构建系统 | Gradle (Kotlin DSL) |
| 多平台 | Kotlin Multiplatform (KMP) |
| 协程框架 | Kotlin Coroutines |
| 编译器插件 | Compose Compiler Plugin |
| 目标平台 | Android、JVM Desktop、iOS、JS、WASM、macOS、Linux、Windows |

### 2.3 核心架构原则

1. **分层设计**：从底层的 Runtime 到顶层的 Material Design，每一层都有明确的职责边界
2. **单向依赖**：上层模块依赖下层模块，下层模块不依赖上层模块
3. **跨平台抽象**：通过 `commonMain` 实现跨平台共享代码，平台特定代码放在 `androidMain`、`desktopMain` 等目录
4. **状态驱动 UI**：使用 Snapshot 状态系统实现自动 UI 更新
5. **组合优于继承**：所有 UI 组件通过组合构建，没有继承层次结构

## 3. 模块详细设计

### 3.1 Runtime 模块 (`:compose:runtime:runtime`)

#### 3.1.1 职责
Runtime 是 Compose 的核心引擎，负责状态管理、组合树的生命周期和重组调度。

#### 3.1.2 核心类与接口

| 类/接口 | 职责 |
|---------|------|
| `Composer` | 组合器核心接口，管理 Composable 函数的执行和 Slot Table 的读写 |
| `Recomposer` | 重组调度器，监听状态变化并调度重组任务 |
| `Composition` | 表示一次完整的组合过程，管理 Composable 的状态和执行 |
| `SlotTable` | 插槽表，使用 Gap Buffer 数据结构存储组合树信息 |
| `SlotReader` / `SlotWriter` | 插槽表的读写器，支持并发读取和独占写入 |
| `Snapshot` | 快照状态系统，实现状态变更的观察和管理 |
| `MutableState` | 可变状态接口，`mutableStateOf()` 的返回类型 |
| `remember` | 记忆函数，在重组间保持值 |
| `CompositionLocal` | 局部组合，在组合树中传递隐式数据 |

#### 3.1.3 Slot Table 数据结构

```
┌─────────────────────────────────────────────────────────────┐
│                        Slot Table                           │
├─────────────────────────────────────────────────────────────┤
│  Group Array (组信息数组)                                    │
│  ┌─────────┬───────┬───────┬───────┬───────┬─────────────┐ │
│  │  Key    │ Flags │ Nodes │ Size  │ Parent│   Slots     │ │
│  ├─────────┼───────┼───────┼───────┼───────┼─────────────┤ │
│  │ 1234    │ <none>│   0   │   3   │  -1   │     0       │ │
│  │ 4567    │ <none>│   0   │   1   │   0   │     0       │ │
│  │ 4567    │ <none>│   0   │   1   │   0   │     1       │ │
│  └─────────┴───────┴───────┴───────┴───────┴─────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  Slot Array (数据数组)                                       │
│  ┌─────────────────┬─────────────────┐                     │

```

#### 3.1.4 平台支持
- Android (`androidMain`)
- Desktop JVM (`desktopMain`)
- iOS (`iosMain`)
- macOS (`macosMain`)
- Linux (`linuxMain`)
- Windows (`mingwMain`)
- JS (`jsMain`)
- WASM (`wasmJsMain`)

### 3.2 UI 核心模块 (`:compose:ui:ui`)

#### 3.2.1 职责
UI 模块是 Compose UI 系统的编排层，负责布局、输入、绘制和节点管理。

#### 3.2.2 核心类与接口

| 类/接口 | 职责 |
|---------|------|
| `LayoutNode` | 布局节点，Compose UI 树的核心节点，管理子节点和测量过程 |
| `Modifier` | 修饰符接口，用于装饰和扩展 UI 元素行为 |
| `MeasurePolicy` | 测量策略，定义子元素的测量和放置规则 |
| `Measurable` / `Placeable` | 可测量/可放置接口，布局系统的核心抽象 |
| `DrawScope` | 绘制作用域，提供 Canvas 绘制上下文 |
| `PointerInputScope` | 指针输入作用域，处理手势输入 |
| `Owner` | 平台抽象，连接 Compose 与平台渲染系统 |
| `AndroidComposeView` / `AbstractComposeView` | Android 平台的 Compose 视图实现 |

## 4. 核心业务流程

### 4.1 Composable 编译流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    @Composable 函数编译流程                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  源代码                          Kotlin 编译器 + Compose 插件                │
│  ┌─────────────────┐           ┌─────────────────────────────────────┐     │
│  │ @Composable      │           │ 1. 识别 @Composable 注解             │     │
│  │ fun Greeting(    │           │ 2. 添加 $composer 隐式参数            │     │
│  │   name: String   │  ======>  │ 3. 插入 startGroup/endGroup 调用     │     │
│  │ ) {              │           │ 4. 添加 changed 检查逻辑              │     │
│  │   Text("Hi $name")│           │ 5. 生成跳过 (Skipping) 逻辑           │     │
│  │ }                │           │ 6. 生成重启 (Restarting) 逻辑          │     │
│  └─────────────────┘           └─────────────────────────────────────┘     │
│                                                                             │
│  编译后代码 (简化示意)                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ fun Greeting(name: String, $composer: Composer, $changed: Int) {   │   │
│  │   $composer.startRestartGroup(1234)                                │   │
│  │   val changed = $composer.changed(name)                            │   │
│  │   if (changed || !$composer.skipping) {                            │   │
│  │     Text(name, $composer, 0)                                       │   │
│  │   } else {                                                         │   │
│  │     $composer.skipToEndGroup()                                     │   │
│  │   }                                                                │   │
│  │   $composer.endRestartGroup()?.updateScope { ... }                  │   │
│  │ }                                                                  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 组合 (Composition) 流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Composition 组合流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 初始组合 (Initial Composition)                                           │
│  ┌─────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │ 调用    │ -> │ Composer    │ -> │ SlotTable   │ -> │ LayoutNode  │      │
│  │Composable│   │ startGroup  │    │ 写入组信息   │    │ 树构建      │      │
│  └─────────┘    └─────────────┘    └─────────────┘    └─────────────┘      │
│                                                                             │
│  2. 状态变化触发重组                                                          │
│  ┌─────────┐    ┌─────────────┐    ┌─────────────┐                         │
│  │ 状态变更 │ -> │ Snapshot    │ -> │ Recomposer  │                         │
│  │(State++) │   │ 通知观察者   │   │ 调度重组    │                         │
│  └─────────┘    └─────────────┘    └─────────────┘                         │
│                                                                             │
│  3. 重组 (Recomposition)                                                     │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐                     │
│  │ Recomposer  │ -> │ Composer    │ -> │ 比较参数变化 │                     │
│  │ 执行重组    │   │ 读取旧Slot   │   │ 决定是否跳过 │                     │
│  └─────────────┘    └─────────────┘    └─────────────┘                     │
│        │                                                            │      │
│        ▼                                                            ▼      │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐                     │
│  │ 参数未变化   │    │ 参数已变化   │    │ 应用变更    │                     │
│  │ 跳过执行    │    │ 重新执行    │ -> │ applyChanges│                     │
│  │ (Skipping)  │    │ Composable │    │ 更新UI树    │                     │
│  └─────────────┘    └─────────────┘    └─────────────┘                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
