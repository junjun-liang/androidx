## 1. 项目概述

### 1.1 项目简介

RemoteCompose 是 Jetpack Compose 生态系统中的一个子项目，提供了一套将 UI 树和绘制命令序列化为二进制格式，并在远程设备（Player）上播放回放的系统。它支持动态表达式、动画和交互元素，而无需完整重新序列化文档。

### 1.2 核心特性

- **二进制序列化**：将 UI 树和绘制命令序列化为紧凑的二进制格式
- **远程播放**：在目标设备上解码和播放序列化的文档
- **动态表达式**：支持基于 RPN（逆波兰表示法）的数学表达式和逻辑运算
- **动画支持**：时间驱动的动画，无需持续与主机通信
- **交互元素**：触摸事件处理和本地状态更新
- **跨平台创建**：支持 Java 程序化 API 和 Kotlin DSL 两种创建方式
- **Compose 集成**：提供 `@RemoteComposable` 注解，使用类似 Compose 的语法创建远程文档

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 编程语言 | Java、Kotlin |
| 构建系统 | Gradle (Kotlin DSL) |
| 多平台 | Android (JVM)、JVM Desktop |
| 目标平台 | Android (View 和 Compose 两种播放器) |
| 序列化格式 | 自定义二进制协议 |
| 表达式引擎 | RPN（逆波兰表示法）栈式求值 |

### 2.3 核心架构原则

1. **创建-传输-播放分离**：文档创建、二进制传输、播放渲染三个环节完全解耦
2. **平台无关的核心**：`remote-core` 是纯 Java 库，不依赖 Android 或 Compose
3. **双向 API 风格**：同时支持程序化 Java/Kotlin API 和声明式 Compose-like API
4. **表达式驱动动画**：使用 RPN 表达式引擎在播放器端本地计算动画，减少通信开销
5. **状态本地化**：触摸交互和状态变更在播放器端处理，无需回传主机

## 3. 模块详细设计

### 3.1 remote-core 模块 (`:compose:remote:remote-core`)

#### 3.1.1 职责
remote-core 是整个系统的心脏，定义了二进制协议和编解码逻辑，负责解码和维护远程文档的状态。

#### 3.1.2 核心类与接口

| 类/接口 | 职责 |
|---------|------|
| `CoreDocument` | 平台无关的 RemoteCompose 文档，包含操作和状态，负责解析和执行远程操作序列 |
| `RemoteContext` | 播放远程文档的抽象上下文，拦截文档中的不同操作并作出反应，包含 PaintContext |
| `Operations` | 定义核心操作码映射（如 `DRAW_RECT`、`LAYOUT_BOX`），管理所有操作的注册和查找 |
| `WireBuffer` | 基础通信缓冲区，负责各种数据类型的编码和解码，使用可增长的字节数组 |
| `RemoteClock` | 提供时间相关操作，控制远程文档中的时间进度和动画 |
| `LayoutCompute` | 布局计算接口，参与布局计算的操作实现此接口 |
| `PaintContext` | 为绘制操作提供上下文信息，包括画布、画笔等相关属性 |
| `SystemInfo` | 系统信息，用于缓冲区解析期间的元数据传递 |

### 3.2 remote-creation-core 模块 (`:compose:remote:remote-creation-core`)

#### 3.2.1 职责
提供面向开发者的文档创建核心 API，是创建端的基础库。

#### 3.2.2 核心类

| 类 | 职责 |
|----|------|
| `RemoteComposeWriter` | 高级 API，向缓冲区发射命令 |
| `RemoteComposeContext` | Kotlin DSL 包装器，提供更符合语言习惯的布局构建方式 |

### 3.3 remote-creation 模块 (`:compose:remote:remote-creation`)

#### 3.3.1 职责
提供程序化 API 创建 RemoteCompose 文档，支持 Kotlin DSL 和 Java 两种风格。

#### 3.3.2 两种 API 风格

**Procedural API (程序化)**：
```kotlin
val rc = RemoteComposeContextAndroid(500, 500, "Demo", platform) {
    root {
        column(Modifier.fillMaxSize().padding(16f)) {
            text("Title", fontSize = 24f)
            box(Modifier.size(100f).background(Color.BLUE))
        }
    }
}
```

**Compose-like API**：
```kotlin
@RemoteComposable @Composable
fun MyDemo() {
    RemoteColumn(
        modifier = RemoteModifier.fillMaxSize().background(Color.White).padding(16.dp),
        horizontalAlignment = RemoteAlignment.CenterHorizontally,
    ) {
        RemoteText("Hello World", fontSize = 38.sp, fontWeight = FontWeight.Bold)
    }
}
```

### 4.2 表达式引擎求值流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    RPN 表达式引擎求值流程                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  表达式定义 (创建端)                                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │  数学表达式: (A + B) * 2                                            │   │
│  │                                                                     │   │
│  │  RPN 表示: [A_ID, B_ID, ADD, 2.0, MUL]                             │   │
│  │                                                                     │   │
│  │  序列化为 ANIMATED_FLOAT 或 DATA_FLOAT 操作                          │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  运行时求值 (播放器端)                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   FloatExpression.eval()                                            │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   初始化空栈 []                                                     │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   遍历 RPN 数组:                                                    │   │
│  │   ┌─────────────────────────────────────────────────────────────┐  │   │
│  │   │ A_ID -> 压栈 [A_value]                                      │  │   │
│  │   │ B_ID -> 压栈 [A_value, B_value]                             │  │   │
│  │   │ ADD   -> 弹出 B,A -> 计算 A+B -> 压栈 [A+B]                │  │   │
│  │   │ 2.0   -> 压栈 [A+B, 2.0]                                    │  │   │
│  │   │ MUL   -> 弹出 2.0,A+B -> 计算 (A+B)*2 -> 压栈 [result]     │  │   │
│  │   └─────────────────────────────────────────────────────────────┘  │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   返回栈顶值 = (A + B) * 2                                          │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  依赖追踪与脏检查                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   每个表达式跟踪其依赖的变量                                           │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   当变量 (Time/TouchX/State) 变化时                                   │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   标记依赖该变量的所有表达式为 "dirty"                                 │   │
│  │        │                                                            │   │
│  │        ▼                                                            │   │
│  │   下次求值时重新计算                                                 │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.1 Procedural API (Kotlin DSL)

```kotlin
import androidx.compose.remote.creation.RemoteComposeContextAndroid
import androidx.compose.remote.creation.core.RemoteComposeWriter
import androidx.compose.remote.core.operations.Header

fun myDemo(): RemoteComposeWriter {
    val rc = RemoteComposeContextAndroid(
        platform = AndroidxRcPlatformServices(),
        apiLevel = 7,
        RemoteComposeWriter.hTag(Header.DOC_WIDTH, 500),
        RemoteComposeWriter.hTag(Header.DOC_HEIGHT, 400),
    ) {
        root {
            column(Modifier.fillMaxSize().background(Color.WHITE).padding(16)) {
                text("Hello World", fontSize = 64f)
                box(Modifier.size(100f).background(Color.BLUE))
            }
        }
    }
    return rc.writer
}
```
