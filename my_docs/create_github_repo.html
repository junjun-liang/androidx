请手动创建 GitHub 仓库

由于 API 认证问题，请按照以下步骤手动创建仓库：

  1. 访问 https://github.com/new
  2. Repository name: androidx-docs
  3. Description: AndroidX 项目软件架构设计、业务流程文档及 Glance+RemoteCompose 微件入门手册
  4. 选择 Public（公开）
  5. 不要勾选 "Add a README file"
  6. 点击 "Create repository"
  7. 创建完成后，在终端执行以下命令推送文档：
cd /Users/liangyingjie/Documents/my_android_projects/androidx/my_docs
git remote set-url origin git@github.com:junjun-liang/androidx-docs.git
git push -u origin main

或者使用 HTTPS 方式：

cd /Users/liangyingjie/Documents/my_android_projects/androidx/my_docs
git remote set-url origin https://github.com/junjun-liang/androidx-docs.git
git push -u origin main
