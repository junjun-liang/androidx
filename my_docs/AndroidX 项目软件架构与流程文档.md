## 1. 项目概览

AndroidX（Jetpack）是 Google 维护的 Android 开发库集合，为 Android 开发者提供向后兼容的 API、架构组件、声明式 UI 框架等核心能力。项目采用**多模块单仓库（Monorepo）**架构，包含数百个独立发布的库模块。

**核心特征：**

| 特征 | 说明 |
|------|------|
| 仓库规模 | 60+ 顶层功能域，数百个 Gradle 子项目 |
| 构建系统 | Gradle + 高度定制化的 buildSrc 插件体系 |
| 语言 | Kotlin 为主，部分 Java 遗留代码 |
| 多平台 | 核心模块支持 KMP（Android/Desktop/iOS/WASM 等） |
| 版本策略 | 语义化版本 + 预发布周期（Alpha→Beta→RC→Stable） |
| CI/CD | Trunk-Based Development，单一开发分支 `androidx-main` |
| 输出目录 | 所有构建输出统一到 `../../out`，与源码树分离 |

### 3.2 根层配置

#### 3.2.1 build.gradle（根项目）

极其精简，仅 30 行，核心作用：

- 通过 `SdkHelperKt.setSupportRootFolder()` 设置项目根目录
- 应用 `AndroidXRootPlugin`，委托给 `applyAndroidXRootImplPlugin.gradle` 加载真正的 `AndroidXRootImplPlugin`

**设计亮点**：薄壳/实现分离，将实现逻辑从类路径中分离，使 Gradle 能更精确判断任务的 up-to-date 状态。

#### 3.2.2 settings.gradle（核心配置枢纽）

这是整个项目最关键的配置文件，承担以下职责：

| 职责 | 说明 |
|------|------|
| 插件管理仓库 | 优先使用本地 `prebuilts/androidx/`，仅 `ALLOW_PUBLIC_REPOS` 时回退公共仓库 |
| 构建脚本依赖 | protobuf、develocity、GCP build cache、AGP 等 |
| 项目过滤（BuildType） | 12 种构建类型：MAIN/COMPOSE/FLAN/MEDIA/WEAR/GLANCE/TOOLS/KMP/CAMERA/NATIVE/WINDOW/XR |
| 项目依赖图 | 自动解析被过滤项目的传递依赖，确保构建子集时依赖完整性 |
| 模块注册 | 通过 `includeProject` 函数声明式注册，关联 BuildType |
| 远程构建缓存 | 支持 GCP 远程缓存 |
| Develocity | 构建扫描发布到 `https://androidx.develocity.cloud` |

**核心插件功能：**

| 插件 | 作用 |
|------|------|
| `AndroidXRootImplPlugin` | 根项目配置：仓库、构建缓存、Develocity |
